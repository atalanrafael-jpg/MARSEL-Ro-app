# Старые данные

Архивная зона проекта MARSEL / Ro App.

Назначение:
- хранить исторические материалы, которые больше не являются частью активной архитектуры;
- не удалять историческую информацию без отдельного решения;
- не использовать содержимое этой папки как источник активной конфигурации без явной проверки.

Правило:
Новые рабочие файлы и действующие CI/CD workflows размещаются только в актуальной структуре проекта.

Примечание:
Исторические GitHub Actions runs и история Git не переносятся сюда физически: они являются частью истории GitHub и должны сохраняться там. Эта папка используется для архивных файлов репозитория, когда их перенос безопасен и подтверждён.
