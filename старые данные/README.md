# Старые данные

Архивная зона проекта MARSEL / Ro App.

## Назначение
- хранить исторические материалы, которые больше не являются частью активной архитектуры;
- не удалять историческую информацию без отдельного решения;
- не использовать содержимое этой папки как источник активной конфигурации без явной проверки.

## Правила
1. Новые рабочие файлы и действующие CI/CD workflows размещаются только в актуальной структуре проекта.
2. Исторические GitHub Actions runs и Git history не переносятся сюда: они должны сохраняться в GitHub как история.
3. Перед переносом любого workflow или скрипта в эту папку необходимо проверить, что на него нет активных ссылок.
4. Архивирование не означает удаление.
