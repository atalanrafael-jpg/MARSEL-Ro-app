# MARSEL V21.6 — Справочники названий, производителей и брендов

Статус: master-справочник и правила нормализации. Не импортировать в RO App без фактического API mapping.

## 1. Справочник производителей

Поля:
- manufacturer_id
- canonical_name
- short_name
- legal_name (если подтверждено)
- country (если подтверждено)
- website (только официальный источник, если подтверждено)
- status: active / archived / unknown
- source
- verified_at
- notes

Правило: не заполнять юридическое название, страну или сайт догадкой.

## 2. Справочник брендов

Поля:
- brand_id
- canonical_name
- manufacturer_id (если связь подтверждена)
- country (если подтверждено)
- official_website (если подтверждено)
- status
- source
- verified_at

## 3. Производственные группы

Поля:
- group_id
- canonical_name
- parent_group_id (если подтверждено)
- manufacturer_ids
- source
- verified_at

Связь группы с производителем не считать фактом без подтверждения источником.

## 4. Коллекции

Поля:
- collection_id
- brand_id
- canonical_name
- source
- verified_at

## 5. Модели

Поля:
- model_id
- brand_id
- collection_id (если есть)
- canonical_name
- product_type
- source
- verified_at

## 6. Reference / модельный номер

Поля:
- reference_id
- model_id
- canonical_reference
- aliases
- source
- verified_at

Reference не смешивать с серийным номером.

## 7. Серийные номера

Серийный номер — экземплярная характеристика конкретного изделия/часов, а не модель и не reference.

Не помещать серийные номера в общий справочник моделей.

## 8. Варианты написания

Поля:
- alias_id
- entity_type
- entity_id
- source_text
- normalized_text
- confidence
- source
- verified_at

Примеры типов: case, brand, manufacturer, model, reference, product_name.

Автоматическое объединение записей по одному только совпадению alias запрещено.

## 9. Транслитерация

Хранить отдельно:
- исходное название;
- каноническое название;
- поисковую транслитерацию.

Транслитерация не является доказательством того, что две записи относятся к одному объекту.

## 10. Синонимы

Синоним используется для поиска и обнаружения потенциального дубля.

Связь:
синоним → каноническая запись → источник → уровень уверенности → подтверждение.

## 11. Каноническое название изделия

Для серийных/брендовых изделий:
`[Тип] [Бренд] [Модель] [Reference]`

Для ювелирных изделий MARSEL:
`[Вид изделия] [материал/проба, если подтверждено] [вставка, если подтверждено] [артикул]`

Не добавлять характеристики, которых нет в исходных данных.

## 12. Название индивидуального изделия

Индивидуальное изделие не должно получать вымышленного производителя или серийной модели.

Использовать:
`[Вид изделия] [индивидуальный заказ] [внутренний артикул]`

## 13. Часы

Рекомендуемая структура:
`Бренд → Коллекция → Модель → Reference → Калибр → Серийный номер`

Экземплярные характеристики (серийный номер, фактическое состояние, установленная деталь) не превращать в модельные.

## 14. Ювелирные изделия

Рекомендуемая структура:
`Тип → Вид → Бренд/производитель → Коллекция → Модель → Артикул`

Для изделий MARSEL собственного изготовления производитель/бренд указывается только если это подтверждённая бизнес-модель каталога.

## 15. Орфография и пунктуация

Проверять:
- регистр;
- пробелы;
- двойные пробелы;
- дефисы и тире;
- кавычки;
- латиницу/кириллицу;
- недопустимые символы;
- единообразие сокращений.

Автоматическая коррекция юридически значимых названий производителя запрещена без подтверждения.

## 16. Duplicate Name Engine

Выявлять потенциальные совпадения по:
1. точному canonical_name;
2. нормализованному написанию;
3. reference;
4. артикулу;
5. штрихкоду, если есть;
6. серийному номеру — только для экземпляров.

Совпадение названия само по себе не является доказательством дубля.

## 17. Manufacturer/Brand Validator

Проверять:
- бренд существует в справочнике;
- производитель существует в справочнике;
- связь бренд ↔ производитель подтверждена или помечена unknown;
- модель связана с брендом;
- reference связан с моделью;
- серийный номер не используется как reference;
- каноническое название не содержит неподтверждённых характеристик.

## 18. Заполнение справочника

В базовый слой разрешено автоматически заполнять только структурные значения и записи, подтверждённые источником.

Не создавать автоматически реальные компании, бренды, модели, reference, юридические названия или сайты без подтверждения.

## 19. Quality Gate V21.6

Статусы:
- OK
- WARNING
- REVIEW
- ERROR

Ошибки:
- отсутствует обязательный идентификатор;
- модель без бренда;
- reference без модели;
- дублирующий canonical ID;
- серийный номер ошибочно используется как модель;
- неподтверждённая связь manufacturer ↔ brand помечена как факт.

## 20. Источник истины

Для каждой фактической записи сохранять source и verified_at. При конфликте источников не выбирать значение автоматически: запись переводится в REVIEW.

## 21. Безопасность

V21.6 является read-only master-слоем. Он не выполняет POST/PUT/PATCH/DELETE в RO App. Любой последующий импорт требует отдельного mapping и dry-run.
