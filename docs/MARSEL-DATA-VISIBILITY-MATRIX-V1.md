# MARSEL DATA VISIBILITY MATRIX V1

## Назначение

Разделяет обязательные для работы данные и внутреннюю коммерческую информацию. Матрица не отменяет юридические обязанности; государственные контуры исключены из текущего scope по указанию владельца.

## Уровни

- INTERNAL — только руководитель/назначенные роли.
- PARTNER — сотрудник или подрядчик по необходимости.
- CUSTOMER — данные, относящиеся к конкретному клиенту и его заказу.
- PUBLIC — данные, предназначенные для сайта/каталога/публичного канала.
- MARKETPLACE — минимальный набор, необходимый конкретному API площадки.

## Правила

1. Не копировать себестоимость/маржу в публичные карточки.
2. Не отправлять клиентские фотографии на маркетплейс без отдельной необходимости и законного основания.
3. Телефоны в MARSEL используют только категорию **«Мобильный»**.
4. Онлайн-примерка должна отделять временные preview/assets от постоянной клиентской медиатеки.
5. Доступ к финансовым данным предоставляется по роли.
6. Любое новое внешнее поле проходит data-minimization review.
