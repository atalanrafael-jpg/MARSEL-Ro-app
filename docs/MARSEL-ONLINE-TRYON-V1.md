# MARSEL — Онлайн-примерка V1

Status: DESIGN / NOT LIVE

## Цель
Подготовить безопасный модуль онлайн-примерки для каталога ювелирных изделий и очков. Модуль не должен изменять карточку товара или заказ без явного действия пользователя.

## Сценарий
1. Пользователь открывает карточку изделия.
2. Выбирает «Онлайн-примерка».
3. Загружает фотографию или использует поддерживаемый камерой режим.
4. Система показывает изделие как визуальное наложение/примерку.
5. Пользователь может изменить положение, масштаб и ориентацию в пределах возможностей интерфейса.
6. Результат можно сохранить как отдельный preview, не подменяя исходную фотографию клиента.
7. При желании пользователь переходит к запросу/заказу изделия.

## Категории
### Очки
Примерка должна учитывать положение оправы относительно лица. Для корректного масштаба и геометрии нужны средства отслеживания лица/ключевых точек, если такая технология используется.

### Кольца
Для реалистичной примерки требуется определение положения пальца/кисти или иной поддерживаемый интерфейсом способ позиционирования. Размер нельзя считать определённым только по фотографии.

### Серьги / подвески / цепи / браслеты
Используется визуальное позиционирование относительно соответствующей области тела. Масштаб не должен интерпретироваться как фактический размер изделия без отдельной калибровки.

## 3D
Если у изделия есть проверенная 3D-модель, она должна быть связана с canonical product ID. Исходный asset не изменяется; preview использует отдельную ссылку/версию.

## Данные и приватность
- Не сохранять фотографию пользователя без отдельного основания/согласия согласно применимым требованиям.
- Не использовать preview как источник биометрической идентификации.
- Отделять исходную фотографию, временные данные примерки и сохранённый preview.
- Удаление временных данных должно быть предусмотрено архитектурой.

## Коммерческий переход
Preview → карточка изделия → цена → наличие → запрос/заказ.
Онлайн-примерка не должна автоматически резервировать или списывать товар.

## Ограничения
Онлайн-примерка является визуальным инструментом. Она не подтверждает точный размер, посадку, цвет, массу, физическую совместимость или иные характеристики, которые невозможно достоверно определить по preview.

## Ro App
Нужно отдельно сопоставить product ID, media/3D assets, stock, order/request и customer fields с фактическим API Ro App. До проверки live schema production integration не выполняется.

## Безопасность
Документ не авторизует загрузку клиентских фотографий в Ro App и не изменяет production data.
