# MARSEL — Единая фирменная система V1

Статус: `APPROVED-DESIGN-REFERENCE`
Источник: загруженные пользователем визуальные материалы MARSEL в чате от 2026-08-12.

## 1. Назначение

Этот документ является единым визуальным эталоном MARSEL для сайта, каталога, CRM-интерфейсов, социальных сетей, рекламных материалов, документов, упаковки и презентаций.

## 2. Логотип

Основной знак: монограмма `M` внутри декоративного круглого плетёного орнамента.

Обязательные версии:
- основной светлый логотип;
- тёмная инверсия;
- знак/аватар без полного написания;
- горизонтальная версия `MARSEL / ЮВЕЛИРНАЯ СТУДИЯ`.

Правила:
- не изменять пропорции;
- не растягивать и не сжимать;
- не менять рисунок монограммы;
- не добавлять эффекты, тени и градиенты без отдельного утверждения;
- сохранять достаточное свободное поле вокруг знака;
- использовать золотой акцент только как фирменный элемент, а не как основной цвет фона.

## 3. Основная палитра

| Token | HEX | Назначение |
|---|---|---|
| `marsel-graphite` | `#333333` | основной текст, тёмные панели |
| `marsel-gray` | `#6B6B6B` | вторичный текст, границы |
| `marsel-light` | `#E6E6E6` | поверхности, разделители |
| `marsel-gold` | `#C9A96E` | акцент, CTA, иконки, премиальные детали |
| `marsel-white` | `#FFFFFF` | основной фон |

Золотой цвет использовать экономно: CTA, активные состояния, тонкие линии, иконографика, маркеры премиального сегмента.

## 4. Типографика

Заголовки: `Playfair Display`, резерв — `Cormorant Garamond`, затем serif.

Основной интерфейс и текст: `Montserrat`, резерв — `Inter`, затем sans-serif.

Правила:
- H1/H2 — выразительный serif;
- навигация и кнопки — sans-serif;
- основной текст — нейтральный sans-serif;
- не использовать более двух шрифтовых семейств одновременно.

## 5. Визуальный характер

MARSEL должен восприниматься как:

**ювелирная студия → ручная работа → точность → качество → доверие → премиальная сдержанность.**

Запрещается превращать стиль в чрезмерно «люксовый» с большим количеством золота, декоративных градиентов или визуального шума.

## 6. UI-компоненты

### Кнопки

Primary:
- фон `#333333`;
- текст `#FFFFFF`;
- hover — `#C9A96E` с читаемым тёмным текстом.

Secondary:
- прозрачный/белый фон;
- графитовая рамка;
- золотой акцент при hover/focus.

### Карточки

- белая поверхность;
- тонкая граница `#E6E6E6`;
- мягкий радиус;
- минимальные тени;
- фото изделия — главный визуальный элемент.

### Иконки

Линейный стиль, тонкая графика. Базовый цвет — `#333333`; активный/премиальный акцент — `#C9A96E`.

## 7. Фотография товаров

Приоритет:
1. изделие;
2. чистый фон;
3. одинаковая композиция каталога;
4. точная цветопередача металла и камня;
5. минимум декоративных элементов.

## 8. Сайт

Главная структура:
- Hero с брендом MARSEL;
- услуги;
- каталог изделий;
- ремонт;
- изготовление на заказ;
- гравировка;
- преимущества;
- отзывы;
- контакты/карта;
- CTA.

В мобильной версии приоритет: телефон, WhatsApp/мессенджер, запись, маршрут и каталог.

## 9. Социальные сети

Единый шаблон:
- логотип MARSEL;
- белый/графитовый фон;
- золотой акцент;
- единая типографика;
- одинаковая обработка фотографий;
- единые CTA.

Контентные форматы:
- изделие;
- процесс работы;
- до/после ремонта;
- история клиента;
- камень/металл;
- мастерская;
- экспертный совет;
- отзыв;
- предложение.

## 10. Данные контактов

Адрес, телефоны, график, Telegram и социальные идентификаторы **не являются частью неизменяемого брендбука**. Они должны подтягиваться из единого NAP/CRM-источника после проверки актуальности.

Это правило введено потому, что в ранее загруженных визуальных материалах встречаются разные телефонные номера.

## 11. Контроль качества

Перед публикацией проверять:
- логотип соответствует эталону;
- цвета соответствуют tokens;
- типографика соответствует системе;
- нет устаревших контактов;
- нет разных вариантов названия бренда;
- CTA одинаково сформулирован;
- изображение изделия не искажено;
- мобильная версия читаема.

## 12. Статусы внедрения

`FACT` — подтверждено пользователем/источником.

`PENDING` — требуется техническая реализация.

`REVIEW` — требуется визуальная проверка.

`DO NOT MODIFY` — элемент нельзя менять без отдельного утверждения.
