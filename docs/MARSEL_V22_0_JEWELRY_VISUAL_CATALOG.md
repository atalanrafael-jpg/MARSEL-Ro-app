# MARSEL V22.0 — Визуальный каталог ювелирных изделий

Статус: проектная спецификация для каталога MARSEL. Фотографии должны быть собственными, лицензированными или иным образом разрешёнными к коммерческому использованию.

## 1. Категории

### Кольца
Обручальные; помолвочные; классические; с бриллиантами; с драгоценными камнями; с полудрагоценными камнями; печатки; перстни; фаланговые; коктейльные; трансформеры; мужские; женские; детские.

### Серьги
Пусеты; гвоздики; кольца/конго; протяжки; подвесные; каффы; клипсы; английский замок; французский замок; мужские; женские; детские.

### Подвески и кулоны
Кресты; иконки; буквы; именные; сердца; символы; религиозные; геометрические; с камнями; без камней.

### Цепи
Якорные; панцирные; бисмарк; нонна; ромб; лав; кордовые; фантазийные; мужские; женские.

### Браслеты
Цепочные; жёсткие; теннисные; с шармами; кожаные; мужские; женские; детские.

### Колье и ожерелья
Классические; с драгоценными камнями; жемчужные; чокеры; многослойные; трансформеры.

### Броши
Цветочные; животные; символы; геометрические; камеи; тематические.

### Мужские аксессуары
Запонки; зажимы для галстука; печатки; браслеты; цепи; кресты; кольца.

## 2. Карточка изделия

Обязательные поля:
- ID;
- каноническое название;
- тип;
- категория;
- подкатегория;
- бренд;
- производитель;
- коллекция;
- модель;
- артикул;
- материал;
- проба;
- цвет металла;
- масса изделия;
- масса металла;
- вставки;
- размер;
- назначение;
- состояние;
- статус;
- склад/место хранения;
- источник данных.

## 3. Визуальные поля

Фото 1: основное.
Фото 2: обратная сторона.
Фото 3: крупный план.
Фото 4: клеймо/проба.
Фото 5: вставка/камень.
Фото 6: масштаб/на модели — если разрешено.
Фото 7: упаковка — при необходимости.

Для каждого изображения хранить: image_id, тип изображения, источник, дата загрузки, автор/владелец прав, статус использования, связанный товар.

## 4. Фильтры

Тип изделия; категория; подкатегория; бренд; производитель; металл; проба; цвет металла; камень; форма огранки; размер; пол/назначение; коллекция; ценовой диапазон; наличие; состояние.

## 5. Визуальные правила

Основное фото должно быть однозначно связано с конкретной карточкой. Не использовать фотографии сторонних каталогов как собственные изображения. Не присваивать изделию характеристики, которых нет в подтверждённых данных.

## 6. Каноническое название

Рекомендуемый шаблон: [Вид изделия] + [бренд/производитель, если подтверждён] + [модель, если подтверждена] + [ключевая характеристика] + [артикул].

Для индивидуального изготовления использовать внутренний артикул и фактически подтверждённые характеристики; не создавать фиктивного производителя или модели.

## 7. Связи

Изделие → фото → бренд → производитель → модель → материалы → камни → себестоимость → склад → заказ → клиент → услуги/операции → гарантия.

## 8. Безопасность импорта

V22.0 не выполняет автоматическую запись изображений или карточек в RO App без подтверждённой API-сущности и отдельного dry-run. Сторонние изображения не импортируются автоматически.
